# BAM! Group landing page

Scroll-driven landing page for BAM! (Bacotan Anak Muda), a youth media and brand group from Bandung.

Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages works as is). Animations use GSAP and ScrollTrigger from cdnjs; fonts come from Google Fonts.

Contact handles in the closing section are placeholders.
